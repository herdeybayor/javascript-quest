# 🔄 JavaScript Beginner Assessment: Reverse a String

## 🎯 Objective
Write a JavaScript program that reverses a string and prints the result.

---

## ✅ Example
**Input:**
```
hello
```
**Output:**
```
olleh
```

**Input:**
```
JavaScript
```
**Output:**
```
tpircSavaJ
```

---

## 🧠 Your Task
1. Create a variable with any string (e.g., "hello").
2. Write code that reverses the characters in the string.
3. Print the reversed string using `console.log()`.

---

## 💡 Helpful Tips
- A string in JavaScript can be turned into an array of characters with `.split('')`.
- Arrays have a `.reverse()` method that flips their order.
- You can turn an array back into a string with `.join('')`.

## 🌟 Bonus Challenge
1. Wrap your code in a function called `reverseString(str)`.

   ```javascript
   reverseString("JavaScript"); // "tpircSavaJ"
   ```
2. Test it with different inputs.
3. For an extra challenge, reverse the string without using `.reverse()` (hint: use a loop).
